## Línea base reproducida

- PostgreSQL 18 y MinIO: contenedores saludables, publicados sólo en `127.0.0.1`.
- Quality gate del 29/08/2026: formato válido; build .NET con 0 advertencias/0 errores; 32/32 pruebas .NET; EF sin cambios pendientes; NuGet/npm sin vulnerabilidades conocidas; `knip` limpio; 23/23 pruebas React; build Vite correcto.
- E2E aislado: 17/17 bloques aprobados sobre una base PostgreSQL temporal y objetos MinIO con prefijo único eliminado al finalizar.
- API real: `GET /health/live` y `GET /health/ready` responden `200 Healthy` en `http://localhost:5103`.
- Frontend público: acceso cargado desde `http://127.0.0.1:5173/acceso`, estructura accesible, sin desbordamiento horizontal a 390 px y consola sin errores.
- Navegador autenticado: pendiente de regresión por rol; no se introdujeron credenciales sin autorización explícita.

La matriz se actualizará únicamente con evidencia de API, PostgreSQL/MinIO y navegador; una compilación correcta no cambia por sí sola un estado a `VERIFICADO`.
